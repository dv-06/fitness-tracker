# Fitness Tracker

A Python-based fitness tracking application that calculates BMR, TDEE, and provides personalized meal plans.

## Features
- User signup with secure password validation
- BMI calculation
- BMR (Basal Metabolic Rate) calculation
- TDEE (Total Daily Energy Expenditure) based on activity level
- Personalized protein recommendations
- Three fitness goals: Weight Loss, Weight Gain, Muscle Building
- Multiple calorie deficit/surplus plans
- Weekly and monthly projection tracking

## Files
- `registration.py` - Main application with user registration and plan selection
- `calculate.py` - BMR, TDEE, and protein calculations

## How to Use
1. Run `registration.py`
2. Create an account
3. Select your activity level
4. Choose your fitness goal
5. Pick a plan that suits you
6. Follow the daily calorie and protein targets!
